# CIDR Subnet Access Lists with Longest-Prefix Matching

Beamline workstations and remote client consoles often operate within dedicated facility subnets or dynamic IP pools rather than fixed individual IP addresses. We decided to generalize the `AccessList.address` field to accept both individual host IP addresses and CIDR network blocks (e.g., `192.168.1.0/24`, `2001:db8::/64`) using a validated `CharField`, rather than adding a separate network column. To ensure cross-database portability across SQLite, MySQL, and PostgreSQL without relying on database-specific network types, endpoint authorization in `EndpointList` and `AccessKeys` resolves client IPs in Python via `AccessListQuerySet.active_for_ip()`, applying longest-prefix matching (`net.prefixlen` descending) so that specific host or subnet rules take precedence over wider network ranges. Edit URLs were simultaneously decoupled from IP strings to primary keys (`<int:pk>`) to prevent URL routing collisions with CIDR slashes.
